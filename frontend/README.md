# Nimbus Console — Private Cloud Management Platform

A professional multi-page frontend prototype built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome CDN

## Start
Open `index.html` in a browser, or use VS Code Live Server.

## Included pages
- Login / Signup with IAM role selection
- Dashboard
- EC2 / Compute management
- Storage management
- Database management + SQL query console
- Activity logs
- Settings

The project uses `localStorage` for mock frontend state and is structured for future backend API integration.
